# nn_CWFS — Neural Curvature Wavefront Sensor

## Problem Statement

The LFAST primary mirror (OD = 0.76 m, ID = 0.0759 m, f/3.33) uses curvature
wavefront sensing (CWFS) as described by Roddier & Roddier (1993).  Two
PSF images are recorded simultaneously at ±1.4 mm defocus.  The goal of this
module is to predict the first 14 Zernike coefficients (Noll indices 2–15,
piston-free) in physical units of metres OPD from those images.

The scientific challenge is **generalisation**: models are pre-trained on
synthetic PSFs generated by a physical Fraunhofer propagator and then
evaluated (and optionally fine-tuned) on real on-sky data.

---

## Physical Signal

The Roddier ratio signal is computed in pixel space after temporal mean-pooling
T = 32 frames at 50 Hz:

$$r = \frac{I_1 - I_2}{I_1 + I_2 + \varepsilon}, \quad \varepsilon = 10^{-6}$$

Both raw intensities and r are fed to the network.  The defocus magnitude is
fixed at ΔW = 4.5 × 545 nm.

## Competing Architectures

### Architecture A — TransformerCWFS

**Hypothesis:** A shared-weight Vision Transformer encoder is an effective
spatial tokeniser for PSF images.  Cross-attention between the two defocus
streams (I1 → I2) and then from their fusion to the Roddier signal (r) allows
the network to learn the differential curvature signal in a data-driven way,
without hardcoding the Roddier formula as a bottleneck.

```
I1 [B,1,256,256] ─┐
I2 [B,1,256,256] ──┤  PatchEmbed (16×16) + pos_embed
r  [B,1,256,256] ─┘  → 256 tokens × D=256
         │
         │  Stage 1: 4 × shared TransformerBlock (self-attention)
         │  → f1, f2, fr independently
         │
         │  Stage 3: 2 × CrossAttentionBlock
         │    Block 0: Q=f1,   KV=f2   (fuse intra/extra-focal)
         │    Block 1: Q=prev, KV=fr   (refine with Roddier signal)
         │
         │  LN → global average pool → MLPHead(256 → [256,64] → 14)
         ▼
     Z2..Z15  [B, 14]
```

| Attribute            | Value          |
|----------------------|----------------|
| Parameters           | ~4.95 M        |
| Config default       | patch_size=16, embed_dim=256, n_enc_blocks=4, n_cross_blocks=2, n_heads=8 |
| Batch size           | 128            |
| Expected strength    | Long-range spatial context; flexible feature interaction |
| Expected weakness    | May require more data to learn positional structure; no inductive bias toward local spatial features |

---

### Architecture B — CNNCWFS (Siamese ResNet)

**Hypothesis:** A convolutional backbone provides strong local spatial inductive
bias well-matched to PSF morphology.  The ResNet learns to extract per-location
intensity features before a cross-attention fusion stage integrates information
across the two defocus planes.  This should generalise better from synthetic to
real data given the stronger prior on local structure.

```
I1 [B,1,256,256] ─┐
I2 [B,1,256,256] ──┤  Siamese ResNetBackbone (shared weights)
r  [B,1,256,256] ─┘  Stem(3×3,s1)→S1(s2)→S2(s2)→S3(s2)→S4(s2)
                      ch: 32→64→128→256→256, spatial: 256→16
                      → flatten → 256 tokens × C=256
         │
         │  Stage 3: 2 × CrossAttentionBlock
         │    Block 0: Q=f1,   KV=f2   (intra/extra-focal fusion)
         │    Block 1: Q=prev, KV=fr   (Roddier refinement)
         │
         │  global average pool → MLPHead(256 → [128] → 14)
         ▼
     Z2..Z15  [B, 14]
```

| Attribute            | Value          |
|----------------------|----------------|
| Parameters           | ~6.80 M        |
| Config default       | base_ch=32, stage_blocks=2, n_cross_blocks=2, n_heads=8 |
| Batch size           | 256            |
| Expected strength    | Strong local spatial priors; stable BN training; fewer tokens needed |
| Expected weakness    | Fixed receptive field growth; less flexible cross-stream interaction |

## Shared Design Decisions

**Cross-attention fusion (both models):** Rather than concatenating streams or
using only the Roddier ratio, both models preserve I1 and I2 as separate
encoding streams fused by learned cross-attention.  This allows the model to
weight the differential signal adaptively and to exploit asymmetries between
the two defocus planes independently.

**Roddier signal as a third input:** r is encoded as a third independent stream
and injected via a second cross-attention block.  This provides the network
with an explicit physics-derived differential signal while not constraining it
to rely solely on r (unlike classical CWFS reconstructors).

**Shared/Siamese backbone weights:** The same encoder is applied to I1, I2,
and r independently.  This enforces the prior that all three images share the
same underlying spatial structure (same pupil, same PSF kernel).

## Training Pipeline

### Data Format (HDF5)

```
psfs    : [N, 2, H, W]  float16   — channel 0 = I1, channel 1 = I2
labels  : [N, 14]       float32   — Zernike coefficients Z2–Z15, metres OPD
```

> **Unit contract:** Labels must be in metres of OPD.  The training pipeline
> z-scores them internally; physical metrics are reported in nanometres.
> Synthetic data should store this unit in an HDF5 attribute: `label_units = 'metres_opd'`.

### D4 Symmetry Augmentation

The circular aperture has D4 (dihedral-4) symmetry.  Rotating/reflecting
both PSF images and applying the analytically derived 14×14 integer Zernike
transformation matrix to the labels multiplies the effective dataset by 8×
at no generation cost.

The 8 operations are: {identity, 3 rotations × 90°} × {flip, no-flip}.
Mode pairs (cos/sin partners) rotate by their azimuthal order m; radially
symmetric modes (Z4 defocus, Z11 spherical) are invariant.

### Optimisation

| Hyperparameter     | Value                        |
|--------------------|------------------------------|
| Optimiser          | AdamW                        |
| LR schedule        | Linear warmup (500 steps) + cosine decay |
| Learning rate      | 3×10⁻⁴                       |
| Weight decay       | 1×10⁻²                       |
| Loss               | L1 on z-scored labels        |
| Gradient clip      | 1.0                          |
| Mixed precision    | AMP (CUDA only)              |
| Epochs             | 50                           |

## Evaluation Strategy

### 1. Standard evaluation on held-out synthetic test set (10%)

Metrics: per-mode RMS (nm), total WFE RMS (nm), Strehl proxy (Maréchal
approximation at λ = 550 nm).

### 2. Roddier ablation

Run inference twice: once with r, once with r replaced by zeros.  Quantifies
the information contributed by the explicit physics signal vs. what the network
infers from I1/I2 alone.

### 3. Model comparison

Load both checkpoints; each model normalises using its own training statistics.
The test loader must be constructed with `label_stats=None` (raw physical
labels) and pass `labels_are_zscored=False` to `_predict`.  Prints a per-mode
difference table (CNN − Transformer).

### 4. On-sky fine-tuning

Backbone weights are frozen; only the regression head (~83 K params for
Transformer, ~35 K for CNN) is fine-tuned on labelled on-sky data.  This
transfer-learning approach exploits the large synthetic pre-training while
adapting to real PSF statistics.

## Usage

```bash
# Generate synthetic training data
python make_training_data.py --config config/data_generation.yaml --output data/cwfs_synthetic.h5

# Dry-run (validate config without writing data)
python make_training_data.py --config config/data_generation.yaml --dry-run

# Override config values at the command line
python make_training_data.py --config config/data_generation.yaml \
    --simulation.n_examples=500 --output data/small.h5
```

```bash
# Align on-sky intra/extra-focal images and compute Roddier signal
python run_sky_defocus.py
```

```bash
# Train TransformerCWFS
python -m mirror_control.nn_CWFS.train \
    --config mirror_control/nn_CWFS/config/transformer.yaml \
    --hdf5_path /data/cwfs_synthetic.h5

# Train CNNCWFS
python -m mirror_control.nn_CWFS.train \
    --config mirror_control/nn_CWFS/config/cnn.yaml \
    --hdf5_path /data/cwfs_synthetic.h5

# Evaluate and compare on synthetic test set
python -m mirror_control.nn_CWFS.evaluate \
    --compare \
    --ckpt_transformer checkpoints/transformer/best.pt \
    --ckpt_cnn checkpoints/cnn/best.pt \
    --hdf5_path /data/cwfs_synthetic.h5

# Roddier ablation
python -m mirror_control.nn_CWFS.evaluate \
    --ckpt checkpoints/transformer/best.pt \
    --ablate_roddier \
    --hdf5_path /data/cwfs_synthetic.h5

# On-sky fine-tuning (head only)
python -m mirror_control.nn_CWFS.evaluate \
    --ckpt checkpoints/transformer/best.pt \
    --onsky_dir /data/onsky/ \
    --fine_tune \
    --ft_epochs 20
```

Config values can be overridden with `--section.key=value` syntax (the `=` is required), e.g.:

```bash
python -m mirror_control.nn_CWFS.train \
    --config config/transformer.yaml \
    --hdf5_path data.h5 \
    --training.epochs=100 --data.batch_size=64
```
