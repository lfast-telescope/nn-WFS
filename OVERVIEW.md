# nn_WFS — Neural Wavefront Sensor (Curvature WFS)

## Problem Statement

The LFAST primary mirror ($OD = 0.76\text{ m}$, $ID = 0.152\text{ m}$, $f/3.33$, $f = 2.5308\text{ m}$) uses curvature wavefront sensing (CWFS) based on the irradiance transport formulation of Roddier & Roddier (1993). Two defocused PSF images are recorded simultaneously at $\pm\Delta z$ defocus (nominal $\Delta z = 0.369\text{ mm}$, yielding defocus coefficient $c_4 = \Delta z / (16 f_{\#}^2 \sqrt{3}) \approx 1.20\ \mu\text{m}$ OPD).

The goal of this module is to predict Zernike wavefront error coefficients (Noll indices, piston/tip/tilt-free, e.g., $Z_4$–$Z_{15}$ or $Z_4$–$Z_{36}$) in physical units of **metres optical path difference (OPD)** from the intra-focal ($I_1$) and extra-focal ($I_2$) intensity distributions.

The core scientific challenge is **domain generalisation**: models are pre-trained on polychromatic synthetic PSFs generated by an `hcipy` Fraunhofer physical wave-optics propagator with realistic multi-layer atmospheric turbulence (Las Campanas profile), and then evaluated and fine-tuned on real on-sky calibration and telemetry data.

---

## Physical Signal & Multi-Frame Expansion

### Roddier Curvature Signal

The normalized differential curvature signal $r$ is computed per pixel as:

$$r = \frac{I_1 - I_2}{I_1 + I_2 + \varepsilon}, \quad \varepsilon = 10^{-6}$$

Both raw intensity streams ($I_1, I_2$) and the explicit differential signal $r$ can be ingested by the networks.

### Temporal Incoherence & $T^2$ Frame-Pair Combinations

Simulated and on-sky data consist of temporal stacks of $T$ frames (e.g. $T = 8$ or $T = 32$ at $50\text{ Hz}$). Because intra-focal ($I_1$) and extra-focal ($I_2$) streams experience independent atmospheric turbulence realizations for the same underlying mirror state:
- Every intra-focal frame $I_1^{(i)}$ paired with any extra-focal frame $I_2^{(j)}$ ($i, j \in \{1, \dots, T\}$) forms a physically valid training sample sharing the exact same mirror Zernike label.
- This provides an automatic $T^2$ data multiplication factor per mirror state without requiring additional optical simulations.

## Model Architectures

The framework supports four distinct model architectures configured via `model.type`:

### 1. TransformerCWFS (`type: transformer`)

**Hypothesis:** A Vision Transformer (ViT) encoder tokenises spatial PSF structure without convolutional inductive bias limitations. Cross-attention blocks between streams allow learned data-driven fusion of intra/extra-focal features and refinement against the Roddier signal.

```
I1 [B, 1, 256, 256] ─┐
I2 [B, 1, 256, 256] ──┤  PatchEmbed (16×16) + Learnable Pos Embed
r  [B, 1, 256, 256] ─┘  → 256 spatial tokens × D=256
         │
         │  Stage 1: 4 × Shared TransformerBlock (Self-Attention)
         │  → f1, f2, fr independently
         │
         │  Stage 2: 2 × CrossAttentionBlock
         │    Block 0: Q=f1,   KV=f2   (fuse intra/extra-focal)
         │    Block 1: Q=prev, KV=fr   (refine with Roddier signal)
         │
         │  LayerNorm → Global Average Pool → MLPHead (256 → [256, 64] → n_outputs)
         ▼
     Z_out  [B, n_outputs]
```

- **Parameters:** ~4.95 M
- **Key attributes:** Long-range spatial context, flexible cross-stream attention interaction.
- **Input modes supported:** `two_stream`, `r_stack`, `pairs`.

---

### 2. SIAMCNN / CNNCWFS (`type: cnn`)

**Hypothesis:** A 4-stage convolutional ResNet backbone provides strong local spatial inductive bias well-matched to localized PSF diffraction features and obscuration ring geometry.

```
I1 [B, 1, 256, 256] ─┐
I2 [B, 1, 256, 256] ──┤  Siamese ResNetBackbone (shared weights)
r  [B, 1, 256, 256] ─┘  Stem(3×3, s1) → S1(s2) → S2(s2) → S3(s2) → S4(s2)
                         Channels: 32 → 64 → 128 → 256 → 256, Spatial: 256 → 16
                         → Flatten → 256 spatial tokens × C=256
         │
         │  Stage 2: 2 × CrossAttentionBlock
         │    Block 0: Q=F1,   KV=F2   (intra/extra-focal fusion)
         │    Block 1: Q=prev, KV=Fr   (Roddier refinement)
         │
         │  Global Average Pool → MLPHead (256 → [128] → n_outputs)
         ▼
     Z_out  [B, n_outputs]
```

- **Parameters:** ~6.80 M
- **Key attributes:** Fast convergence, strong local spatial priors, BatchNorm stability.
- **Input modes supported:** `two_stream`, `r_stack`, `pairs`.

---

### 3. RODCNN — Cross-Batch Roddier CNN (`type: rodcnn`)

**Hypothesis:** Curvature sensing physics is fundamentally differential. By explicitly computing all $T \times T = T^2$ Roddier images across temporal frame combinations within each mirror state, a single-stream ResNet can learn pure curvature features. Training on the mean prediction across all $T^2$ pairs directly optimizes for mirror aberration invariance against dynamic atmospheric turbulence.

```
Single Example: I1 [T, 1, H, W] and I2 [T, 1, H, W]  (same mirror state, independent turbulence)
         │
         │  Vectorized T² Cartesian expansion inside forward():
         │  Pair every I1_i with every I2_j → r_ij = (I1_i - I2_j) / (I1_i + I2_j + ε)
         │  → r_all [T², 1, 256, 256]
         │
         │  Single-Stream ResNetBackbone (no cross-attention needed)
         │  Stem(32) → S1(64) → S2(128) → S3(256) → S4(256)
         │  → [T², 256, 16, 16] → Flatten → Tokens [T², 256, 256]
         │  → Mean Pool → [T², 256] → MLPHead (256 → [128] → n_outputs)
         │  → Predictions [T², n_outputs]
         ▼
    pred = pred_all.mean(dim=0)  [n_outputs]
    loss = MSE(pred, example_label) / accumulate_every
```

- **Batching & Optimization:** Fed one example ($T$ frames) per iteration; gradients are accumulated over `batch_size` examples before stepping the optimizer.
- **Key attributes:** Eliminates cross-attention overhead, maximally leverages $T^2$ atmospheric diversity, directly targets turbulent phase noise reduction.

---

### 4. SLPCWFS — Toy Model Baseline (`type: toy`)

**Hypothesis:** A lightweight single-hidden-layer perceptron with patch embedding serves as a fast baseline to quantify the performance gain provided by deep ResNet and Transformer representations.

```
Roddier r / R [B, 1, 256, 256]
         │  PatchEmbed (16×16) → 256 tokens × D=128
         │  Token Mean Pool → [B, 128]
         │  Linear(128 → 150) → GELU → Dropout
         │  Linear(150 → n_outputs)
         ▼
     Z_out  [B, n_outputs]
```

## Input Modes Summary

| Input Mode | Input Shapes | Processing Description | Used By |
|---|---|---|---|
| `two_stream` | `I1: [B, T, H, W]`, `I2: [B, T, H, W]` | Encodes each temporal frame independently through backbone, mean-pools features across $T$, then executes cross-attention between $I_1$ and $I_2$. | `transformer`, `cnn` |
| `r_stack` | `R: [B, T², H, W]` | Ingests all $T^2$ pre-computed Roddier combinations, treating each frame as an independent training sample with replicated labels. | `transformer`, `cnn`, `toy` |
| `pairs` | `I1, I2, r: [B, 1, H, W]` | Single frame pair plus explicit Roddier signal. Alternating cross-attention over $I_2$ and $r$. | `transformer`, `cnn`, `toy` |
| `rodcnn` | `I1: [T, 1, H, W]`, `I2: [T, 1, H, W]` | Per-example temporal stack expanded to $T^2$ Roddier signals on-the-fly, evaluated through a single-stream backbone, and averaged over $T^2$. | `rodcnn` |

## Flexible Noll Mode Subsetting & Pairing Completeness

### Arbitrary Mode Sets (`model.trained_modes`)

Rather than hardcoding a fixed set of modes, models can be trained on arbitrary subsets of Noll Zernike indices via the `trained_modes` config list (e.g. `[4, 5, 6, ..., 15]` for $Z_4$–$Z_{15}$, or `[5, 6, ..., 36]` for $Z_5$–$Z_{36}$).

If `model.trained_modes` is omitted (or set to `null` / `"all"`), the pipeline automatically defaults to **all modes available in the HDF5 dataset minus piston, tip, and tilt** ($Z_4$ through $Z_N$, i.e. `list(range(4, n_modes_hdf5 + 1))`).

`dataset.py` extracts and reorders only the requested mode columns from HDF5 on-the-fly, allowing a single 36-mode synthetic dataset to train and benchmark models targeting different Zernike ranges.

### Pairing-Completeness Constraint

Because the aperture has circular/dihedral symmetry, any spatial rotation mixes the cosine and sine partner modes of a given azimuthal frequency $m$ (e.g. $Z_5$ oblique astigmatism and $Z_6$ vertical astigmatism). The configuration validator (`validate_trained_modes_pairing`) enforces that for every mode with $m \neq 0$, its corresponding $\pm m$ partner is also included. Radially symmetric modes ($m = 0$, such as $Z_4$ defocus and $Z_{11}$ spherical aberration) are singletons and exempt from pairing requirements.

## D4 Dihedral Symmetry Augmentation

The circular pupil and square detector grid possess $D_4$ dihedral symmetry (order 8):
- 4 rotations ($0^\circ, 90^\circ, 180^\circ, 270^\circ$) $\times$ 2 reflections (flip, no-flip).

`D4Augment` randomly applies one of these 8 spatial operations to $I_1, I_2, r, R$ while multiplying the Zernike label vector by an exact analytical $N_{\text{modes}} \times N_{\text{modes}}$ transformation matrix:
- Radially symmetric modes ($m = 0$) are invariant (diagonal $= 1$).
- Mode pairs with azimuthal order $m > 0$ transform via $2 \times 2$ blocks:
  - Pure rotation by $\phi = k \cdot 90^\circ$: $R_m(\phi) = \begin{bmatrix} \cos(m\phi) & -\sin(m\phi) \\ \sin(m\phi) & \cos(m\phi) \end{bmatrix}$
  - Reflection + rotation: $F_m(\phi) = \begin{bmatrix} \cos m(\pi + \phi) & \sin m(\pi + \phi) \\ \sin m(\pi + \phi) & -\cos m(\pi + \phi) \end{bmatrix}$

This multiplies the effective training dataset by **$8\times$** at zero computational generation cost.

## Training Pipeline & Optimisation

### HDF5 Dataset Format

The dataset generator produces HDF5 files with the 5-D temporal schema:

```
psfs   : [N, 2, T, H, W]  float16   — channel 0 = I1, channel 1 = I2
labels : [N, n_modes]     float32   — Zernike coefficients in metres OPD
attrs  : label_units = 'metres_opd', n_modes = <int>
```

> **Unit Contract:** Ground truth labels are stored in **metres OPD**. `train.py` z-scores labels internally per mode based on the training split statistics, while all evaluation metrics are denormalized and reported in physical **nanometres RMS**.

### Hyperparameters & Features

| Parameter | Default / Options | Description |
|---|---|---|
| **Optimizer** | `AdamW` | Weight decay $10^{-2}$, initial learning rate $3 \times 10^{-4}$ |
| **LR Schedule** | Linear Warmup + Cosine / Constant | 500 warmup steps with cosine decay or constant rate |
| **Loss** | MSE ($L_2$) on z-scored labels | Optimized for minimum WFE variance across modes |
| **Mixed Precision** | PyTorch AMP (`torch.amp.GradScaler`) | Automatic mixed precision for CUDA acceleration |
| **JIT Compilation** | `torch.compile(mode=...)` | `reduce-overhead` (Transformer/CNN/Toy) or `default` (RODCNN) |
| **Checkpoints** | `CheckpointManager` | Tracks the best model in memory during training; writes a single `resume.pt` (overwritten each epoch, deleted on completion) and one permanent `final_wfe*nm.pt` per seed |
| **Early Stopping** | Patience (e.g. 30 epochs), min delta | Early termination if validation WFE ceases to improve |

## Evaluation & On-Sky Transfer

1. **Synthetic Test-Set Evaluation (`eval_synthetic`):**
   Reports per-mode RMS error ($\text{nm}$), total wavefront error RMS ($\text{nm}$), and Strehl proxy via Maréchal approximation ($S \approx \exp[-(2\pi \sigma_{\text{WFE}} / \lambda)^2]$ at $\lambda = 550\text{ nm}$).
2. **Roddier Channel Ablation (`ablation_roddier`):**
   Evaluates inference with $r$ active vs. $r = 0$, quantifying the empirical benefit of explicit physical differential features versus learned two-stream representations.
3. **Side-by-Side Model Comparison (`compare_models`):**
   Loads multiple checkpoints (e.g. Transformer vs. CNN) and evaluates them on a unified unnormalized test loader, printing a per-mode delta comparison table.
4. **On-Sky Inference & Head Fine-Tuning (`eval_onsky`):**
   Supports zero-shot inference on on-sky `.npy` pairs or transfer learning by freezing the feature backbone and fine-tuning only the regression `MLPHead` on labeled on-sky calibration data.

## Usage Guide

### 1. Synthetic Data Generation

```bash
# Generate polychromatic synthetic dataset with atmospheric turbulence
python make_training_data.py --config config/data_generation.yaml --output data/cwfs_synthetic.h5

# Dry run (validates config, grids, and basis without writing)
python make_training_data.py --config config/data_generation.yaml --dry-run

# Command-line parameter override
python make_training_data.py --config config/data_generation.yaml \
    --simulation.n_examples=2000 --output data/cwfs_2k.h5
```

### 2. Model Training

```bash
# Train TransformerCWFS
python train.py --config config/transformer.yaml --hdf5_path data/cwfs_synthetic.h5

# Train SIAMCNN (Siamese ResNet)
python train.py --config config/cnn.yaml --hdf5_path data/cwfs_synthetic.h5

# Train RODCNN (Cross-Batch Roddier CNN)
python train.py --config config/rodcnn.yaml --hdf5_path data/cwfs_synthetic.h5

# Train SLPCWFS (Toy Baseline)
python train.py --config config/toy.yaml --hdf5_path data/cwfs_synthetic.h5
```

*Config parameters can be overridden using `--section.key=value` syntax:*
```bash
python train.py --config config/rodcnn.yaml \
    --hdf5_path data/cwfs_synthetic.h5 \
    --training.epochs=100 --training.lr=1e-4 --data.batch_size=16
```

### 3. Evaluation, Comparison, & Fine-Tuning

```bash
# Evaluate a single checkpoint on the test split
python evaluate.py \
    --ckpt checkpoints/rodcnn/epoch045_wfe18.2nm.pt \
    --hdf5_path data/cwfs_synthetic.h5

# Side-by-side model comparison (Transformer vs. CNN)
python evaluate.py \
    --compare \
    --ckpt_transformer checkpoints/transformer/best.pt \
    --ckpt_cnn checkpoints/cnn/best.pt \
    --hdf5_path data/cwfs_synthetic.h5

# Roddier channel ablation
python evaluate.py \
    --ckpt checkpoints/transformer/best.pt \
    --ablate_roddier \
    --hdf5_path data/cwfs_synthetic.h5

# On-sky fine-tuning (backbone frozen, fine-tuning MLP head)
python evaluate.py \
    --ckpt checkpoints/rodcnn/best.pt \
    --onsky_dir /data/onsky/ \
    --fine_tune \
    --ft_epochs 25
```
